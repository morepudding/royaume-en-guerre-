# Royaume en Guerre

Jeu de stratégie médiéval mobile construit avec Next.js et React.

Cette version contient :

- 15 missions de campagne ;
- le choix d'envoi de `¼`, `½` ou `TOUT` des troupes ;
- les batailles lorsque deux armées se croisent sur une route ;
- une interface pensée pour le mobile et le mode paysage ;
- une progression sauvegardée localement dans le navigateur.

## Lancer le projet

```bash
npm install
npm run dev
```

Puis ouvrir <http://localhost:3000>.

## Vérifier la version de production

```bash
npm run build
npm start
```

Version actuellement publiée : <https://royaumes-en-guerre.vercel.app>
